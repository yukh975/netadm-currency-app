# Changelog — Конвертер валют (Android)

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
`versionName` задаётся вручную (SemVer) и держится единым с Telegram-ботом;
`versionCode` растёт автоматически (номер пайплайна CI). Каждая сборка ветки
`android` публикуется как GitLab Release (раздел Releases).

## [0.4.0] — 2026-06-16

### Added
- **Динамика курса в сводке** (оба источника): рядом с каждым курсом —
  изменение к предыдущему курсу в «моей валюте», `(+0.50)` зелёным / `(−0.07)`
  красным (в приложении настоящий цвет, в уведомлении — обычным текстом).
  Для ЦБ предыдущий курс берётся из поля `Previous`; для рыночного приложение
  само запоминает прошлые курсы (динамика появляется со 2-го обновления).

### Changed
- **Заголовок уведомления — на дату действия курса.** ЦБ публикует курсы
  заранее, и они действуют со следующего дня; теперь уведомление пишет
  «Курсы валют на DD.MM.YYYY» (для ЦБ — завтрашнюю дату, для рыночного — дату
  источника), а не «на сегодня».

## [0.3.6] — 2026-06-16

### Changed
- Поля ввода (сумма, поиск валюты): статичная подсказка **внутри рамки**
  (`placeholder`) вместо «плавающего» заголовка, который уезжал вверх и зеленел
  при фокусе. Поиск в избранном больше не растягивается по высоте; подсказка
  укорочена до одной строки.

## [0.3.5] — 2026-06-16

### Fixed
- **Системная навигация выглядела «пустой белой»** на Android 15: добавлен
  вызов `enableEdgeToEdge()` — системные бары прозрачны, а их иконки получают
  корректный контраст под светлую тему.

## [0.3.4] — 2026-06-16

### Fixed
- **Нижняя панель навигации уезжала под системную навигацию Android 15**
  (edge-to-edge включается принудительно при targetSdk 35): добавлен отступ
  `navigationBarsPadding()` — иконки больше не перекрываются системной панелью.

## [0.3.3] — 2026-06-16

### Changed
- Совместимость с требованиями Google Play 2026: `compileSdk`/`targetSdk` → 35
  (Android 15), AGP 8.6.
- Минимизация разрешений: убран лишний `FOREGROUND_SERVICE` (подмешивался
  WorkManager) — приложение запрашивает только `INTERNET` и `POST_NOTIFICATIONS`
  плюс обычные `WAKE_LOCK`/`ACCESS_NETWORK_STATE`/`RECEIVE_BOOT_COMPLETED`.

### Added
- Материалы для публикации в Google Play и RuStore: пошаговый
  [`store/PUBLISHING.md`](store/PUBLISHING.md), графика магазинов (SVG: иконка
  512×512, feature 1024×500, скриншоты), политика конфиденциальности на Telegraph;
  актуализированы карточки RU/EN (e-mail, «что нового», фичи, точный источник).

## [0.3.2] — 2026-06-16

### Fixed
- **Приложение не запускалось** в 0.3.0/0.3.1: R8-минификация
  (`isShrinkResources`/R8) вырезала нужное на старте. Минификация **отключена** —
  сборка снова запускается. Размер APK вернулся к ~11 МБ; правила R8 сохранены
  для будущего возврата с диагностикой по логу краша.

## [0.3.1] — 2026-06-16

### Fixed
- Открытие сводки из уведомления теперь считается относительно «моей валюты»
  (как и текст уведомления), а не текущей исходной валюты конвертера.
- Удаление выбранной исходной валюты из избранного больше не оставляет
  «висящий» выбор: конвертер/сводка возвращаются к «моей валюте».
- `launchMode=singleTask` у MainActivity — повторный тап по уведомлению при
  запущенном приложении доставляется в `onNewIntent`, без пересоздания экрана.
- Защитный `keep` на конструктор `MainViewModel` (страховка от R8).

## [0.3.0] — 2026-06-16

### Added
- Настройка **«Моя валюта»** — постоянная домашняя валюта. Относительно неё
  считается сводка в ежедневном уведомлении.

### Changed
- В конверторе исходная валюта по умолчанию равна «моей валюте» и переключается
  **временно**, не меняя настройку. Ручная сводка (кнопка) следует за этим
  выбором — это удобно.
- Уведомление-сводка теперь всегда считается относительно «моей валюты», а не
  последней валюты, выбранной в конверторе.
- Имя выходных файлов сборки: `currency-converter-<версия>` (APK/AAB).
- Включены R8-минификация и удаление неиспользуемых ресурсов — меньше размер APK.

## [0.2.0] — 2026-06-16

### Added
- Кнопка «🔔 Сводка курсов» на экране конвертации — курсы избранных валют к
  основной по запросу. Данные обновляются принудительно (всегда свежие).
- Тап по ежедневному уведомлению открывает приложение и показывает сводку.
- Выбор времени ежедневного уведомления в настройках (по умолчанию 17:00 МСК).

### Changed
- Формат сводки (уведомление и по запросу): для каждой избранной валюты одна
  строка вида «1 EUR = 90.50 RUB» — курс к основной валюте, с одинаковым числом
  знаков после запятой (2). Убраны конвертация суммы и обратный курс.
- Версия приложения переведена на ручной SemVer и синхронизирована с ботом
  (0.2.0); `versionCode` по-прежнему берётся из номера пайплайна CI.

## [0.1.18] — 2026-05-28

### Added
- Принудительное обновление курсов кнопкой в настройках + время последнего обновления.
- Вкладка «О программе»: описание, версия, ссылки на сайт yukh.net и Telegram-бот.
- Авто-инкремент версии в CI и автоматический GitLab Release с APK/AAB.

### Changed
- Нижняя навигация: 4 иконки + центрированная подпись активной вкладки.
- «Основная валюта» переименована в «Исходная валюта».
- В конверторе цифровая клавиатура; скрытие клавиатуры по «Конвертировать».
- Ввод валюты текстом убран — исходная валюта выбирается чипсом.

## [0.1.17] — 2026-05-28

### Added
- Первая версия Android-приложения (Kotlin + Jetpack Compose).
- Два источника курсов: ЦБ РФ и Google (рыночный курс).
- Избранные валюты с поиском, выбор исходной валюты, конвертация.
- Удобный формат курса для дешёвых валют, кэш курсов (3 ч).
- Ежедневное уведомление-сводка (~17:00 МСК).
- Подписанная сборка APK/AAB в GitLab CI.
