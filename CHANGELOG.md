# Changelog — Конвертер валют (Android)

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
`versionName` = `0.1.<номер пайплайна CI>`, версия растёт на каждой сборке.

## [Unreleased]

### Added
- Принудительное обновление курсов кнопкой в настройках + время последнего обновления.
- Вкладка «О программе»: описание, версия, ссылки на сайт yukh.net и Telegram-бот.
- Авто-инкремент версии в CI и публикация GitLab Release с APK/AAB.

### Changed
- Нижняя навигация: 4 иконки + центрированная подпись активной вкладки.
- «Основная валюта» переименована в «Исходная валюта».
- В конверторе цифровая клавиатура; скрытие клавиатуры по «Конвертировать».

## [0.1.0] — 2026-05-28

### Added
- Первая версия Android-приложения (Kotlin + Jetpack Compose).
- Два источника курсов: ЦБ РФ и Google (рыночный курс).
- Избранные валюты с поиском, выбор исходной валюты, конвертация.
- Удобный формат курса для дешёвых валют, кэш курсов (3 ч).
- Ежедневное уведомление-сводка (~17:00 МСК).
- Подписанная сборка APK/AAB в GitLab CI.
