# 💱 Конвертер валют

Простой и быстрый конвертер валют для Android по курсам **Центрального банка
РФ** или **рыночным (мид-маркет) курсам**. Без рекламы, без регистрации, без
сбора данных.

## Возможности

- Интерфейс на русском и английском — по умолчанию язык системы, в настройках
  можно переключить вручную.
- Два источника курсов на выбор — 🇷🇺 ЦБ РФ (`cbr-xml-daily.ru`) и 🌐 рыночный
  (мид-маркет) курс через ExchangeRate-API (`open.er-api.com`) — тот же тип
  курса, что показывает конвертер Google. При источнике ЦБ РФ приложение также
  обращается к `isdayoff.ru` (производственный календарь РФ), чтобы не опрашивать
  источник в нерабочие дни, когда новый курс не публикуется.
- Все валюты ЦБ РФ, включая редкие (сербский динар, тенге, лари и др.).
- «Моя валюта» — постоянная домашняя валюта, относительно неё считается сводка.
- Избранные валюты: поиск по коду, названию или стране.
- Конвертация из «моей» или любой валюты — исходную валюту можно временно
  переключить, не меняя настройку.
- Удобный формат для «дешёвых» валют: «100 RSD = 73 RUB» вместо дробей.
- Курсы кэшируются и работают без сети между обновлениями.
- Ежедневное уведомление-сводка с курсами избранных валют (время настраивается,
  по умолчанию 17:00 МСК); рядом с курсом — изменение к предыдущему
  (+0.50 / −0.07). Тап по уведомлению открывает сводку.
- Дата актуальности курса и время последнего обновления — всегда на виду.

## Конфиденциальность

Приложение не собирает и не передаёт персональные данные. Все настройки
хранятся только на устройстве.
[Политика конфиденциальности](https://telegra.ph/Politika-konfidencialnosti--Konverter-valyut-06-16).
