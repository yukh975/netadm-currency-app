# Карточка приложения — RU

## Название
Конвертер валют

## Короткое описание (≤ 80 символов)
Курсы ЦБ РФ и рыночные: избранные валюты, офлайн-кэш, ежедневная сводка

## Полное описание (≤ 4000 символов)
💱 Простой и быстрый конвертер валют по курсам Центрального банка РФ или
рыночным (мид-маркет) курсам.

Возможности:
• Два источника курсов на выбор — 🇷🇺 ЦБ РФ и 🌐 рыночный (мид-маркет) курс.
• Все валюты ЦБ РФ, включая редкие (сербский динар, тенге, лари и др.).
• «Моя валюта» — постоянная домашняя валюта, относительно неё считается сводка.
• Избранные валюты: поиск по коду, названию или стране.
• Конвертация из «моей» или любой валюты: введите «1000» или «USD 100».
  Исходную валюту можно временно переключить, не меняя настройку.
• Удобный формат для «дешёвых» валют: «100 RSD = 73 RUB» вместо дробей.
• Курсы кэшируются и работают без сети между обновлениями.
• Ежедневное уведомление-сводка с курсами избранных валют (время настраивается,
  по умолчанию 17:00 МСК); тап по уведомлению открывает сводку.
• Дата актуальности курса и время последнего обновления — всегда на виду.

Без рекламы, без регистрации, без сбора личных данных. Все настройки хранятся
только на вашем устройстве.

## Что нового (релиз 0.4.0)
• Динамика курса в сводке (ЦБ РФ): рядом с курсом изменение к предыдущему
  — (+0.50) зелёным / (−0.07) красным.
• Уведомление-сводка: заголовок на дату, на которую действует курс.
• Настройка «Моя валюта», кнопка «Сводка курсов», настраиваемое время уведомления.
• Стабильность запуска и корректная раскладка под Android 15.
