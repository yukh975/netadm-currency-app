# Графика для магазинов

Исходники — SVG (векторные, правятся в любом редакторе). Перед загрузкой в
магазин **экспортируйте в PNG** в указанных размерах.

| Файл | Назначение | Размер PNG | Формат |
|------|-----------|-----------|--------|
| `icon-512.svg` | Иконка приложения (Google Play + RuStore) | **512×512** | PNG, без прозрачности (заливка до краёв) |
| `feature-graphic.svg` | Feature graphic (Google Play) | **1024×500** | PNG/JPG, **без альфа-канала** |
| `screenshot-1-convert.svg` | Скриншот: конвертация | **1080×1920** | PNG/JPG (9:16) |
| `screenshot-2-summary.svg` | Скриншот: сводка курсов | 1080×1920 | PNG/JPG |
| `screenshot-3-favorites.svg` | Скриншот: избранное | 1080×1920 | PNG/JPG |
| `screenshot-4-settings.svg` | Скриншот: настройки | 1080×1920 | PNG/JPG |

Скриншоты — **оформленные макеты** (не реальные кадры устройства). Магазины их
принимают. При желании замените на реальные скриншоты 0.3.3 с телефона —
требования те же (9:16, сторона 320–3840 px).

## Экспорт SVG → PNG

**librsvg (рекомендуется, macOS):**
```bash
brew install librsvg
cd store/assets
rsvg-convert -w 512  -h 512  icon-512.svg          -o icon-512.png
rsvg-convert -w 1024 -h 500  feature-graphic.svg   -o feature-graphic.png
for f in screenshot-*.svg; do rsvg-convert -w 1080 -h 1920 "$f" -o "${f%.svg}.png"; done
```

**Или cairosvg (Python):**
```bash
pip install cairosvg
cairosvg icon-512.svg -o icon-512.png -W 512 -H 512
```

**Или без установки:** откройте SVG в Chrome → распечатать/сделать снимок, либо
загрузите на онлайн-конвертер (cloudconvert.com и т.п.) с нужными размерами.

> ⚠️ Эмодзи-флаги (🇷🇺, 🇺🇸 …) в скриншотах рендерятся, только если в системе
> экспорта есть emoji-шрифт. На macOS librsvg может не отрисовать цветные
> эмодзи — тогда коды валют (RUB, USD) останутся, а флаги пропадут. Для
> гарантии экспортируйте через браузер (Chrome рендерит эмодзи) или замените
> макеты на реальные скриншоты.
