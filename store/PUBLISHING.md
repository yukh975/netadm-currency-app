# Публикация в Google Play и RuStore

Пошаговый runbook для приложения **Конвертер валют** (`net.yukh.currency`).
Версия для подачи — **0.3.3** (targetSdk 35, минимальный набор разрешений).

Артефакты собираются в GitLab CI: подписанные `currency-converter-<версия>.aab`
и `.apk` лежат в **Releases** и в Package Registry. Материалы карточек и
графика — в этом каталоге `store/`.

## 1. Разрешения (важно для проверки Google Play!)

Прошлый отказ был из-за лишних разрешений. Здесь набор **минимальный**.
Итоговый манифест после сборки содержит только:

| Разрешение | Тип | Зачем | Объявлять в консоли |
|-----------|-----|-------|---------------------|
| `INTERNET` | normal | Загрузка курсов (cbr-xml-daily.ru, open.er-api.com) | Не требует деклараций |
| `POST_NOTIFICATIONS` | runtime (A13+) | Ежедневная сводка-уведомление (локальная) | Data safety: данные не собираются |
| `ACCESS_NETWORK_STATE` | normal | Условие «есть сеть» для фоновой задачи | — |
| `WAKE_LOCK` | normal | WorkManager во время задачи | — |
| `RECEIVE_BOOT_COMPLETED` | normal | Перепланировать уведомление после перезагрузки | — |

`FOREGROUND_SERVICE` (его подмешивает WorkManager) **намеренно удалён** через
`tools:node="remove"` — foreground-сервис не используется. **Опасных
разрешений нет** (геолокация, контакты, хранилище, камера — отсутствуют).

## 3. Google Play — первая подача (аккаунт у вас уже есть)

targetSdk 35 уже выставлен, так что блокер снят. Дальше — в Play Console:

1. **Create app**: имя «Currency Converter» / «Конвертер валют», язык по
   умолчанию, тип App, бесплатное, принять декларации.
2. **App content** (раздел «Контент приложения») — заполнить ВСЕ пункты (§4).
3. **Main store listing**: иконка 512×512, feature graphic 1024×500, ≥2
   (лучше ≥4) скриншота, заголовок ≤30, короткое ≤80, полное ≤4000, категория
   Финансы, контактный e-mail `yukh975@gmail.com`.
4. **Upload AAB**: загрузите `currency-converter-0.3.3.aab`. Согласитесь на
   **Play App Signing** (Google сгенерирует ключ подписи; ваш релизный keystore
   становится *upload-ключом* — храните его, но при утере можно сбросить).
5. ⚠️ **Тест-гейт для Individual-аккаунта** (созданного после 13.11.2023):
   перед Production нужен **Closed-тест ≥12 тестеров в течение 14 дней подряд**,
   затем заявка на доступ к Production. Organization-аккаунты — без этого гейта.
6. Создайте релиз (Internal/Closed → потом Production), приложите AAB, напишите
   release notes, отправьте на проверку.

> Обновления потом можно лить автоматически из CI (см. §6).

## 4. Google Play — ответы для деклараций (копировать как есть)

- **Privacy policy URL**: telegra.ph-ссылка (EN) из §0.
- **App access**: всё доступно без логина/регистрации (нет учётных записей).
- **Ads**: «No» — рекламы нет.
- **Content rating (IARC)**: пройдите опросник как утилита/финансы без
  нежелательного контента → рейтинг «Everyone / 3+».
- **Target audience**: 13+/взрослые, **НЕ дети** (не Designed for Families).
- **Data safety**: **данные не собираются и не передаются**, трекинга нет.
  Уведомления локальные. Сетевые запросы — только публичные курсы без PII.
- **Financial features**: ⚠️ объявить **НЕТ регулируемых финансовых функций**
  (нет займов/кредитов, банкинга, крипто-обмена, инвестиций/трейдинга,
  платежей/переводов, страхования). Это информационный конвертер курсов —
  лицензии и документы не нужны. **Не отмечайте** пункты про займы/кредиты.
- **Government / News / COVID**: «No» (не относится).

## 5. RuStore — первая подача

1. **Аккаунт**: регистрация через **VK ID**, бесплатно. Для бесплатного
   приложения хватает аккаунта **физлица** (мгновенная активация, без УКЭП).
   ⚠️ Но **API-ключи для автозаливки доступны только юрлицу** — у физлица
   публикация и обновления только **вручную** в консоли.
2. **Создать приложение** для `net.yukh.currency`: имя «Конвертер валют»,
   категория Финансы, возраст **3+**, короткое (≤80) и полное (≤4000) описания
   из `listing-ru.md`, e-mail `yukh975@gmail.com`, URL политики (RU из §0).
3. **Графика**: иконка 512×512 (без прозрачности, заливка до краёв), ≥1
   скриншот 9:16 реального UI.
4. **Подписанный артефакт**: загрузите AAB (для AAB сначала зарегистрируйте
   ключ подписи в консоли) или APK. Подпись должна быть **той же** для всех
   будущих обновлений — у RuStore нет управляемой подписи как у Google.
5. **Данные**: объявить «персональные данные не собираются».
6. Отправить на модерацию (обычно до 24 ч).

## 6. Автозаливка обновлений через CI (после первой подачи)

Первую версию каждого магазина создают **вручную** (API не создаёт приложение
с нуля). Дальше обновления можно лить автоматически — задачи в `.gitlab-ci.yml`
запускаются вручную (`stage: deploy`) при наличии переменных:

**Google Play** — задача `publish-googleplay` (скрипт `publish_googleplay.py`):
1. В Google Cloud создайте **сервис-аккаунт**, включите Android Publisher API.
2. В Play Console → Users & permissions пригласите сервис-аккаунт с правом
   «Release to testing/production» для этого приложения.
3. CI-переменная `PLAY_SA_JSON_B64` = `base64` от JSON сервис-аккаунта.
   (Прошлый затык был на правах API-доступа — проверьте, что сервис-аккаунту
   выданы права именно на это приложение.)

**RuStore** — задача `publish-rustore` (скрипт `rustore_publish.py`, **нужен
аккаунт юрлица**):
1. Консоль RuStore → Компания → «API RuStore» → сгенерировать пару ключей.
2. CI-переменные `RUSTORE_KEY_ID` и `RUSTORE_KEY_B64` = `base64` от приватного
   RSA-ключа (PEM). Скрипт уже шлёт обязательные `minAndroidVersion`,
   `developerContacts`, `isMainApk` — при первом запуске сверьте ответы API.

Версию приложения для нового релиза поднимайте в обеих ветках синхронно
(`APP_VERSION` в `.gitlab-ci.yml` + `appVersionName` в `app/build.gradle.kts`,
и версия бота в `CHANGELOG.md` ветки `main`).

## 7. Подпись (keystore) — беречь!

Релизный keystore (CI-переменные `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`,
`KEY_ALIAS`, `KEY_PASSWORD`) должен сохраняться **для всех будущих обновлений**:
- Google Play: это upload-ключ (потеря восстановима через сброс).
- RuStore: управляемой подписи нет — потеря ключа **блокирует обновления**.
Сделайте офлайн-резервную копию файла и паролей.

## 8. Открытые вопросы / на потом

- **Название источника «Google»**: в приложении/боте рыночный источник назван
  «🌐 Google», хотя реально это `open.er-api.com`. В карточках уже исправлено на
  «рыночный (мид-маркет) курс». Рекомендуется переименовать и в UI приложения и
  бота, чтобы избежать претензий по товарному знаку (см. ветку `android` и `main`).
- **R8/минификация** отключена (APK ~11 МБ) — можно вернуть позже с точными
  keep-правилами по логу краша (см. CHANGELOG 0.3.2).
- **Скриншоты** — сейчас оформленные SVG-макеты; при желании замените на
  реальные кадры 0.3.3 с устройства.
